BC Energy Step Code Dashboard — Data Column Reference

As of November 19, 2026 · Liam Butters

Each table below lists a dashboard chart or filter next to the exact workbook column(s) behind it (source file: NRCan Database Analysis.xlsx, "Conditioned Data" tab, via extract_data.py). "Avg." charts show the mean of the column across homes matching the current filters, excluding blank cells (and, for a few columns noted below, a 0 sentinel the workbook uses for "not computed"). 2026 is labelled "H1 2026" on every chart axis/tooltip, since the extraction only covers the first half of the year so far.

Calculated columns

The "Conditioned Data" tab isn't raw data - it's the output of a Power Query (M code) embedded in the workbook itself, which adds every calculated column below on top of the raw HOT2000/EnerGuide export. This traces each one back to the columns it's built from, read directly from that query (customXml/item1.xml in the .xlsx → the embedded DataMashup package → Formulas/Section1.m).

Airtightness

The workbook recognizes three separate compliance paths for airtightness (ACH50, NLR, NLA) and a home only needs to clear one of them at a given step - so each path gets its own step column, and a fourth column combines them into the home's actual airtightness step.

ColumnBuilt fromHow
Calc'd NLRAIR50P, HSEVOL, LEAKAR, NLA(AIR50P × HSEVOL ÷ 3.6) ÷ (LEAKAR ÷ NLA), rounded
ACH Step AchievedAIR50P (raw ACH50), TYPEOFHOUSE, BUILDINGTYPE≤1.0→5, ≤1.5→4, ≤2.5→3 (or ≤3.0 for non-single-detached houses), else no step (null)
NLR Step AchievedCalc'd NLR≤0.35→5, ≤0.53→4, ≤0.89→3, else no step (null)
NLA Step AchievedNLA≤0.48→5, ≤0.72→4, ≤1.2→3 (and not exactly 0, which the workbook treats as "not computed"), else no step (null)
Airtightness StepACH Step Achieved, NLR Step Achieved, NLA Step AchievedThe best (highest) of the three paths; "FAIL" (shown as Fail) only if all three are null

The Airtightness step achieved, by year chart and the dashed threshold lines on the Avg. ACH50, Avg. NLA, and Avg. NLR charts all read directly from this table's thresholds.
